## Стек технологий (Планируемый)
### Backend:
- **Язык**: Java
- **Фреймворк**: Spring Boot
- **База данных**: PostgreSQL
- **Инфраструктура**: Docker, GitHub

### Frontend:
- **Язык**: TypeScript, HTML / CSS
- **Фреймворк**: React
