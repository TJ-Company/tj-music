# TJ music
> Данное веб-приложение создано для загрузки, скачивания и воспроизведения музыки

## Стек технологий (Планируемый)
### Backend:
- **Язык**: Java
- **Фреймворк**: Spring Boot
- **База данных**: PostgreSQL
- **Инфраструктура**: Docker, GitHub

### Frontend:
- **Язык**: TypeScript, HTML / CSS
- **Фреймворк**: React
